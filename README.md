# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Players can compete against the computer, and the game instantly displays the winner based on the traditional Rock-Paper-Scissors rules.

## 🚀 Features

* User-friendly interface
* Random computer choice generation
* Instant result display
* Score tracking for player and computer
* Responsive design
* Interactive hover and click effects

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and layout
* **JavaScript (ES6)** – Game logic and interactivity

## 🎯 How to Play

1. Open the game in your web browser.
2. Choose one of the following options:

   * ✊ Rock
   * ✋ Paper
   * ✌️ Scissors
3. The computer will randomly select its choice.
4. The winner is determined based on the rules:

   * Rock beats Scissors
   * Scissors beats Paper
   * Paper beats Rock
5. Scores are updated automatically after each round.
